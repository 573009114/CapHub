# CapHub 上线前检查清单（MVP）

## 1. 配置与密钥
- [ ] `JWT_SECRET` 已在生产环境中配置为高强度随机值（禁止默认值）。
- [ ] `DATA_FILE` 指向持久化卷路径（容器重启不丢失）。
- [ ] `TENANT_QUOTA_QPS` 已按租户容量规划设置。
- [ ] `INIT_DB_ON_START` 在生产默认关闭（避免误重置数据）。
- [ ] 关键配置由环境变量或密钥管理系统注入，不写死在镜像中。

## 2. 数据与备份
- [ ] 数据文件目录具备读写权限、磁盘空间和监控。
- [ ] 已验证数据快照恢复流程（模拟进程重启后数据一致）。
- [ ] 已定义备份周期与保留策略（例如每日全量 + 最近 N 份）。
- [ ] 已验证“备份恢复演练”可在 RTO/RPO 目标内完成。

## 3. 接口与安全
- [ ] 所有受保护接口均强制鉴权（Bearer 或兼容头策略明确）。
- [ ] RBAC 权限矩阵完成验收（`action:*` / `skill:execute` / `audit:read`）。
- [ ] 多租户越权测试通过（跨租户查询/执行均拒绝）。
- [ ] CORS 策略与前端域名策略匹配（生产不建议 `*` 放开所有域）。
- [ ] 高风险 Skill 执行需 `confirm_high_risk=true` 的流程已在前端联调。

## 4. 可靠性与性能
- [ ] 常规回归测试和 `-race` 测试通过。
- [ ] 压测达到目标并记录基线（吞吐、P95/P99、错误率）。
- [ ] 限流与幂等机制已在峰值流量场景验证。
- [ ] 上游 API 超时、失败、异常 JSON 等降级路径已验证。

## 5. 观测与审计
- [ ] 审计日志包含 trace_id、租户、用户、动作、状态、耗时。
- [ ] 失败执行可通过 trace_id 快速检索链路。
- [ ] 关键指标已接入告警：
  - [ ] 错误率（5xx / 4xx 异常波动）
  - [ ] 延迟（P95/P99）
  - [ ] 限流命中率（429）
  - [ ] 磁盘使用率与数据文件写入失败

## 6. 发布与回滚
- [ ] 发布前锁定版本（镜像 tag / commit SHA）。
- [ ] 具备一键回滚方案（回滚镜像 + 恢复数据快照）。
- [ ] 已完成灰度/金丝雀策略（如有）。
- [ ] 变更窗口、负责人、应急联系人、回滚触发阈值已明确。

## 7. 运行手册（Runbook）
- [ ] 启停、配置、日志路径、常见故障排查步骤文档化。
- [ ] 新租户初始化、权限授予、API 注册流程文档化。
- [ ] 故障演练记录（鉴权失败、上游超时、数据恢复）已归档。
